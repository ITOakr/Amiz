採用：1a 3列グリッド ＋ 1d タブ ＋ 1i 数字優先
採用案 1a＋1d＋1i を1台にまとめたもの
この1台に入っているもの
1a D キーボードは3列グリッド。記号と名前を並記した目ボタン6種、その下に「先に選ぶ」修飾5種と段の操作4種。
1d A／B はタブで切り替え。記号図に高さを全部渡して、目数表は同じ場所に差し替える。
1i C 現在の段は数字優先。「拾った目／前段の目数」を大きく出し、直前に編んだ3目だけ添える。

実際に編めます。目ボタンを押すと赤くハイライトされた前段の目の真上に記号が積まれ、赤い短い線でその目に編み込んだことを示してハイライトが次へ進みます。
