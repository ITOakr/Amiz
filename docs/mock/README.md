## 扱い方

- **レイアウトと操作感の参考**として使う。仕様の正はあくまで `docs/ui-spec.md`
- HTML・CSS・JavaScript のコードは実装に流用しない。画面は SwiftUI で作る
- HTML は `support.js` と `_ds/` を読み込む作りのため、単体ではそのまま表示されない
- まずスクリーンショットを見る。挙動の詳細を確認したいときだけ HTML を読む

## 仕様と異なる点（仕様書が正しい）

このモックは、次の点が `docs/ui-spec.md` の内容に追いついていない。

- 繰り返しの回数が ×2・×3・×4 と「段の終わりまで」しか選べない（仕様では任意の数を入力できる）
- 細編みの段のみを想定しており、立ち上がりを1目と数える段（中長編み・長編み）が試せない
- 目数の警告が「足りない場合」のみ（仕様では拾いすぎた場合も警告する）
- 目を選択したときの操作が削除のみ（仕様では種類の変更と繰り返しの解除もできる）
- 「色を編集」「書き出し」はメニューに項目があるだけで、中身は未作成
