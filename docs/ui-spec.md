# かぎ針編み図アプリ 画面・操作仕様書

このドキュメントは、アプリの画面構成と操作を定義する。編み物のルール（目の数え方、修正時の整合性など）は「ドメイン仕様書（domain-spec.md）」で定義しており、本書で「ドメイン仕様○」と書いた箇所はそちらの番号を指す。

UIモックの作成にも使うことを想定し、画面ごとの状態とサンプルデータを含める。

---

## 0. アプリの概要

- **何をするアプリか**：かぎ針編みの編み図（記号図・目数表）を作るiOSアプリ
- **対象ユーザー**：かぎ針編みをする人。あみぐるみ、モチーフ、平面の作品を作る
- **最大の特徴**：記号を画面に並べて描くのではなく、**実際に編むのと同じ順番で、1目ずつボタンを押して編み進める**と、記号図と目数表が自動で出来上がる
- **対応端末**：iPhone（縦向きのみ）、iPad（縦横両対応）

## 1. デザイン方針

- 見た目の雰囲気・配色・フォントはデザイン側の提案に任せる。
- **記号図が主役**。装飾で図を見にくくしない。
- 編集画面は長時間使うため、ボタンは押し間違えにくい大きさと間隔にする。
- 図の上をタップしても記号が置かれることはない（誤操作を防ぐため、入力はすべてキーボードのボタンで行う）。
- 白など背景に近い糸の色でも、記号が判別できるようにする。

### モックでの記号の簡易表現

モックでは、日本式（JIS）のかぎ針編目記号を次の簡易的な形で描いてよい。

| 目 | 記号の形 |
|---|---|
| 鎖編み | 横長の楕円 |
| 引き抜き編み | 黒く塗った小さな楕円 |
| 細編み | × |
| 中長編み | T |
| 長編み | T の縦線に斜めの横棒1本 |
| 長々編み | T の縦線に斜めの横棒2本 |
| 2目編み入れる | 同じ記号2つを根元で合わせたV字 |
| 2目一度 | 同じ記号2つを上で合わせた逆V字 |

## 2. 画面一覧と遷移

| 番号 | 画面 | 表示方法 |
|---|---|---|
| 1 | 作品一覧（ホーム） | 通常画面 |
| 2 | 新規作成 | シート |
| 3 | 編集画面 | 通常画面（メイン） |
| 4 | 糸リスト | シート |
| 5 | 書き出し | シート |
| 6 | 設定 | 通常画面（作品一覧から開く） |
| 7 | 各種確認ダイアログ | ダイアログ |

**遷移**
- 作品一覧 → 新規作成 → 編集画面
- 作品一覧 → 作品をタップ → 編集画面
- 作品一覧 → 設定
- 編集画面 → 糸リスト／書き出し（シートで開き、閉じると編集画面に戻る）

## 3. 作品一覧（ホーム）

### 要素
- 作品カードのグリッド（iPadは列数を増やす）
  - サムネイル（記号図の縮小表示）
  - 作品名
  - 編み方（往復編み／輪編み／螺旋編み）
  - 段数（例：「4段目まで」）
  - 更新日
- 新規作成ボタン
- 設定ボタン
- カードのメニュー（長押し）：名前の変更（テキスト入力のアラート。空にはできない）、複製（「〜のコピー」として同じ編み図とサムネイルで作る。更新日は今なので先頭に来る）、削除（確認してから。元に戻せない）

### 並び順（U19）
更新日の新しい順。

### 状態
- **通常**：作品が並んでいる
- **空の状態**：作品が1つもないとき、「最初の作品を作りましょう」というメッセージと新規作成ボタンを中央に表示

---

## 4. 新規作成（シート）

### 入力項目
- 作品名
- 作り目：わの作り目／鎖の作り目
  - 鎖の作り目を選んだ場合は「1段目に編む目数」を入力する。実際に編む鎖の目数はアプリが計算して添える（例：「細編みなら鎖21目」。ドメイン仕様33）
- 編み方：往復編み／輪編み／螺旋編み
- 最初の糸：色と名前

「作成」を押すと編集画面に移る。

当面作れる組み合わせは「わの作り目 × 輪編み／螺旋編み」と「鎖の作り目 × 往復編み」。作り目を変えると編み方も合うものに切り替わり、合わない組み合わせでは「作成」を押せず理由を添える（鎖を輪にして編み始める作品は今後対応）。

## 5. 編集画面

### 5-1. 構成要素（U2）

| 記号 | 要素 | 役割 |
|---|---|---|
| A | 図 | 自動生成される記号図 |
| B | 目数表 | 段ごとの手順と目数 |
| C | 現在の段 | 今編んでいる段の手順と進み具合 |
| D | 編み目キーボード | 目を編むためのボタン群 |
| E | ツールバー | 画面全体の操作 |

### 5-2. 端末ごとの配置（U3・U4）

**iPhone（縦向きのみ）**：上から順に次のように並べる。
1. E ツールバー
2. A 図／B 目数表（タブなどで切り替え）
3. C 現在の段
4. D 編み目キーボード（画面下部。ソフトウェアキーボードの位置）

**iPad（横向き）**
1. 上：E ツールバー
2. 左カラム上：A 図（画面の大部分）
3. 左カラム下：B 目数表（タブで切り替えず、図と同時に表示する）
4. 右：C 現在の段と D 編み目キーボードを縦に並べた固定レール（幅 392pt 程度）
   - 下部に置くより、iPad を持ったまま押しやすく、図を広く使えるため
   - 目ボタンは 96pt 角程度まで大きくし、記号も大きく描く

**iPad（縦向き）**：iPhoneの配置を大きくしたもの。

### 5-3. A 図

- データから自動で描かれる記号図。輪編み・螺旋編みは円形、往復編みは平面で描く。
- ピンチでズーム、ドラッグで移動。
- **「次に拾う前段の目」をハイライト表示する**。目を1つ編むとハイライトが次の目へ進む。この表示が「実際に編んでいる感覚」の中心になる。
- 今編んでいる段の目は、完成済みの段と区別できるように表示する。
- タップは目の選択のみ（U15）。記号が置かれることはない。
- 記号の線は糸の色で描く（糸が2本以上の作品）。今編んでいる段はアクセント色の縁取りで区別し、色替えの位置には持ち替える目の頭の先に新しい色の小さな三角を付ける（ドメイン仕様31）。
- 段番号を表示する（設定で非表示にできる）。往復編みでは、段の立ち上がり側に段番号と方向の矢印を付ける（1段目は右から左。作り目の鎖は一番下に横一列に描く）。

### 5-4. B 目数表

- 1行につき1段を表示する。項目は、段番号、手順（「（細編み1目、細編み2目編み入れる）×6」など）、目数。
- 手順の文章の書き方（8章のサンプルから決めた。フェーズ1-5）
  - 数えない立ち上がり（鎖1目）と段を閉じる引き抜きは書かない。数える立ち上がりは「立ち上がり鎖3目」と書く
  - 同じ目が続けば「細編み3目」とまとめる。鎖編みは「鎖2目」。飛ばすは「2目飛ばす」
  - 繰り返しは「（…）×6」。単位が1つなら括弧を付けない（「細編み2目編み入れる×6」）
  - 段の終わりまでは、単位が普通の目1つなら「残りの目すべてに細編み」、それ以外の1つなら「細編み2目編み入れる×全目」、複数なら「（長編み1目、鎖2目）を段の終わりまで」
  - 1段目は「わの作り目に」「作り目に」を頭に付ける
  - 色が変わる項目には糸名を付ける（「こげ茶で細編み2目編み入れる」。ドメイン仕様31）
- 先頭に作り目の行を表示する（「わの作り目」または「作り目：鎖21目」。ドメイン仕様33）。
- 鎖を含む段は、目数を「合計36目／鎖抜き12目」のように併記する（ドメイン仕様8）。
- 同じ内容の段が続く場合は、「5〜9段目：細編み30目（増減なし）」のようにまとめて表示する。まとめた行をタップすると展開して1段ずつ表示し、そこから段を選ぶ。
  - まとめる条件：手順が同じで、前の段と目数が同じ段が2段以上続くこと。警告のある段はまとめない（警告が隠れないように）
  - まとめた行の手順は1段分と同じ文章（「残りの目すべてに細編み」）で、目数のあとに「（増減なし）」を付ける
- 目数が合わない段は色を変え、警告文を表示する（例：「前段14目のうち12目しか拾っていません」）。足りない場合だけでなく、拾いすぎた場合も警告の対象になる。
- 段をタップすると、その段の編集に入る（U16）。
- 段を長押しするとメニューを出す（U22）。
  - **この段を削除**
  - **この段を複製**：回数を入力し、同じ手順の段をその段の直後に指定回数ぶん挿入する（「増減なしで5段」に使う。ドメイン仕様18）
  - どちらも、上に段がある場合は修正の確認ダイアログ（7-1）を出す（ドメイン仕様25）

### 5-5. C 現在の段

- 進み具合の数字を主役にする。
  - 「拾った目／前段の目数」を大きく表示する（例：「12/18」）
  - 段番号（例：「4段目」）と、この段の目数（例：「この段 6目」）を添える
  - わの作り目の1段目は前段の目数がないため、「この段 6目」だけを表示する（ドメイン仕様33）
  - 前段の目を使い切ったら、図のハイライトを消して「前段を使い切りました」と表示する。さらに目を編むこともでき、その場合の警告は段を終えたときに出す（ドメイン仕様23）。前段が残っていないときの「飛ばす」は何もしない
- 通常の入力中は、直前に編んだ3目だけを並べて表示する（iPhone の幅では手順を全部並べると読みにくいため）。
  - 例：「細編み｜細編み2目編み入れる｜細編み」
- 過去の段を編集中（U16）は、その段の手順をすべて並べて表示する。
  - 例：「立ち上がり鎖1｜細編み｜細編み｜細編み2目編み入れる｜細編み」
  - 項目の間をタップして入力位置を動かせる
- 手順の項目をタップすると、その目を選択する（U15）。

### 5-6. D 編み目キーボード

ボタンは3つのグループに分けて配置する。

**グループ1：目ボタン（U7）**
鎖編み／引き抜き編み／細編み／中長編み／長編み／長々編み
- 各ボタンに記号と名前を表示する。
- 押すと、今の編み入れ先に1目編み、ハイライトが前段の次の目に進む。
- **立ち上がりの自動挿入（U5）**：その段で最初に**鎖編み以外**の目を押したとき、段の先頭に立ち上がりを自動で入れる（設定でオフにできる）。鎖の目数はその目の種類で決める（細編み1／中長編み2／長編み3／長々編み4／引き抜き編みはなし。ドメイン仕様6）。1目と数えるかは設定「立ち上がりを1目と数える」（6-3）で決める。「毎回選択」のときは、目を入れる前に確認 7-4 を出し、答えてから立ち上がりと目を入れる（キャンセルすると目も入れない）。
  - 鎖編みから始まる段（モチーフの「立ち上がり鎖3目、鎖2目、長編み…」など）は、鎖編みを先に押し、続けて長編みを押した時点で立ち上がりが先頭に入る。
  - 自動で入るのは段ごとに1回だけ。後から目の種類を変えても変わらない。
  - 螺旋編みでは入れない。

**グループ2：先に選ぶボタン（U8〜U10・U12）**
2目編み入れる／2目一度／束に／飛ばす／残りすべてに
- 「2目編み入れる」「2目一度」「束に」「残りすべてに」は、**先に押してから目ボタンを押す**。押すと選択状態（ハイライト）になり、次に押した目1つに適用され、適用後に選択が解除される。
  - 例：「2目一度」→「細編み」＝細編み2目一度
- 「2目編み入れる」「2目一度」は、もう一度押すと3目になる（表示が「3目編み入れる」「3目一度」に変わる）。さらに押すと選択が解除される。データ上は n目に一般化されているが（ドメイン仕様2）、初期バージョンの画面で選べるのは3目までとする。
- 同時に選べる組み合わせ：
  - 「束に」＋「2目編み入れる」：例「束に」→「2目編み入れる」を2回（3目）→「細編み」＝鎖のアーチに細編み3目を束で編み入れる
  - 「残りすべてに」＋「2目編み入れる」「2目一度」「束に」のいずれか：例「残りすべてに」→「2目編み入れる」→「細編み」＝残りの目すべてに細編み2目編み入れる（ドメイン仕様17）
  - 「束に」と「2目一度」は同時に選べない（後に押した方が残る）
  - 「束に」の目は次の鎖のアーチに編み入れ、アーチの間の目は自動で飛ばした扱いになる（ドメイン仕様21）。同じアーチに複数の目を入れるときは「束に」＋「2目編み入れる」
  - 「残りすべてに」を選んで鎖編みを押した場合は、鎖編みは前段を拾わず回数が決まらないので、普通の鎖編み1目として扱う
- 選択状態は、目ボタンを押す前ならもう一度押して解除できる。
- 「飛ばす」は選択状態にならず、押すたびに前段の目を1目飛ばす。
- ドメイン仕様2に記載の「増し目ボタン」は、この「2目編み入れる」ボタンで実現する。

**グループ3：段の操作（U11・U13・U14・U23）**
繰り返し開始／繰り返し終了／段を終える／1目削除／立ち上がり
- **繰り返し**：「繰り返し開始」を押してから目を入力し、「繰り返し終了」を押す。終了時に、繰り返す単位の確認（例：「『細編み・細編み・細編み2目編み入れる』を繰り返します」）と、回数の指定を出す。
  - 回数は任意の数を入力できるようにする（×6 などが必要なため、選択肢を数個並べるだけの形にはしない）
  - 「段の終わりまで」も選べる（ドメイン仕様17）。ただし単位が前段を1目も拾わない場合（鎖編みだけ、など）は選べないようにする
- **段を終える**：編み方に応じて段を閉じる。輪編みは段を閉じる引き抜き（ドメイン仕様7）を自動で入れ、往復編みは編み地を返し、螺旋編みは次の段へ進む。前段に目が残っているときは確認を出す（7-2）。拾いすぎている場合は確認を出さず、段を終えた時点で目数表に警告を出す。
- **1目削除**：文字入力の削除キーのように、直前の1操作を消す。直前の操作が繰り返し（×6 など）なら、繰り返しごと消す。段を終えた直後（入力中の段が空）に押すと「段を終える」を取り消し、前の段の入力に戻る。ツールバーの「元に戻す」とは別。
- **立ち上がり（U23）**：押すと鎖の目数（1〜4）を選ぶメニューを出し、段の先頭に立ち上がりを入れる。すでに立ち上がりがある段では、その鎖の目数の変更になる。自動挿入をオフにしているときや、自動と違う目数にしたいときに使う。螺旋編みでは押せない。1目と数えるかは U5 と同じく設定で決め、「毎回選択」なら確認 7-4 を出す。

### 5-8. 操作の詳細

**U15. 目の選択**
図・現在の段・目数表のどこからでも、タップで目を選択できる。選択中は次の操作ができる。
- 種類の変更：キーボードの目ボタンを押すと置き換わる。繰り返しの中の目を選んでいる場合は、すべての回に反映される（ドメイン仕様15）
- 削除
- 繰り返しの解除：繰り返しの中の目を選んだ場合、繰り返しを1目ずつに展開する
- 立ち上がりを選んだ場合は、種類の変更の代わりに鎖の目数（1〜4）と、1目と数えるかを変更できる。鎖の目数を変えたときの数え方は設定（6-3）に従う（「毎回選択」のときは今の値のまま）

**U22. 段のメニュー**
目数表の段を長押しすると出す。項目は「この段を削除」「この段を複製」（5-4）。

**U16. 過去の段の編集**
- 目数表で段をタップすると、その段が「編集中」になる。
- 現在の段（C）にその段の手順が表示され、項目の間をタップして入力位置を動かし、キーボードで挿入・置き換えをする。
- 画面に「完了」ボタンを表示する。
- 「完了」を押した時点で目数が変わっていて、上に段がある場合は、修正の確認ダイアログ（7-1）を出す。1操作ごとには出さない。

**U17. 糸の持ち替え**
- ツールバーに「今持っている糸」の色を表示する（戻るボタンの隣の色の丸）。
- タップすると糸リストが開き、別の糸に持ち替えられる。
- 新しく編む目は、今持っている糸の色になる。糸が2本以上の作品では、現在の段の項目に糸の色の点を添える。

**U21. 色編集モード**
すでに編んだ目の色を、途中でも最後でも後から変えるためのモード。
- ツールバーの「色を編集」から入る。
- モード中は、編み目キーボード（D）が糸パレットに切り替わる。糸パレットには糸リストの糸と「糸を追加」ボタンを表示する。
- パレットで糸を選び、図の目をタップするとその色に塗る。なぞると続けて塗れる（1回のなぞりは「元に戻す」1回で戻る）。繰り返しの中の目を塗ると、その繰り返しは解除される（ドメイン仕様27）。
- 目数表の段をタップすると、段全体を塗る。
- モード中は目の追加・削除などの編集はできない（段の長押しメニューも出ない。過去の段の編集中には入れない）。図のピンチ（ズーム）は使える。
- 元に戻す／やり直しは使える。
- 「完了」で通常の入力に戻る。
- モード中であることが一目で分かる表示にする：パレットは紫の帯で「色編集モード」と表示し、「完了」ボタンを置く。入ったときの塗る色は今持っている糸。「糸を追加」で追加した糸はそのまま選ばれる。

### 5-9. 編集画面の状態一覧

| 状態 | 内容 |
|---|---|

## 6. 糸リスト・書き出し・設定

### 6-1. 糸リスト（シート）
- 作品で使う糸の一覧。項目は、表示色、名前（「生成り」「メイン色」など）、メモ（糸の品番など。任意）。
- 糸の追加・編集・並べ替え。先頭の糸が既定の糸（ドメイン仕様29）。
- 通常入力中に開いた場合は、タップした糸に持ち替える（U17）。行の右の「i」で名前・色・メモを編集する。
- 削除：その糸で編んだ目は既定の糸に戻る。最後の1本は削除できない。
- 色の選択は標準のカラーピッカー。

### 6-2. 書き出し（シート、U18）
- 形式：PDF／画像
- 含める内容（複数選択）：図／目数表／凡例／糸リスト
- PDFの用紙：A4
- 凡例は、図で使った記号だけを自動で並べる。
- 糸リストは表紙の凡例の下に、色見本・名前・メモを並べる（既定でオン）。図は糸の色で描き、色替えの三角も出す。
- 書き出しボタンでiOS標準の共有シートを開く。ファイル名は「作品名.pdf」「作品名.png」。
- 含める内容が1つも選ばれていないときは書き出せない（ボタンを押せなくし、その旨を添える）。
- 目数が合わない段がある場合は、書き出し前に確認を出す（7-3）。確認はツールバーの「書き出し」を押した時点で出し、「書き出す」を選ぶとこのシートが開く（シートの中では確認を出さない。共有シートを開くボタンの手前に別の確認を挟めないため）。

### 6-3. 設定（U20）
- 立ち上がりの鎖の自動入力：オン／オフ
- 立ち上がりを1目と数える：標準／数える／数えない／毎回選択（既定は標準。ドメイン仕様6）
  - 標準：鎖1目は数えない、鎖2目以上は1目と数える
  - 数える／数えない：細編みの鎖1目を含むすべての立ち上がりに効く
  - 毎回選択：立ち上がりが入るたびに確認 7-4 を出す
  - どれも「これから入れる立ち上がり」の初期値を決めるだけで、入力済みの段は変わらない。後から変えるときは目を選択する（U15）
- 図に段番号を表示：オン／オフ

## 7. 確認ダイアログ

### 7-1. 修正の確認（ドメイン仕様25）
次のとき、上に段がある場合に出す。
- 過去の段の編集を「完了」したとき、目数が変わっている場合
- 段を削除するとき（U22）
- 段を複製するとき（U22）

- メッセージ例：「2段目の目数が12目から14目に変わりました。3〜5段目に影響があります。」「2段目を削除します。3〜5段目に影響があります。」
- 選択肢
  - **上の段を残す**：上の段はそのままにして、合わなくなった段に警告を出す
  - **上の段をほどく**：3〜5段目を削除する
  - **キャンセル**：編集中の状態に戻る（削除・複製の場合は何もしない）

### 7-2. 段を終えるときの確認（U13）
「段を終える」を押したとき、前段に拾っていない目が残っている場合に出す。「段の終わりまで」や「残りすべてに」で割り切れずに余った目（ドメイン仕様17）もここで扱う。
- メッセージ例：「前段18目のうち、あと3目残っています。」
- 選択肢
  - **残りは編まない**：警告を出さずに段を終える
  - **このまま終える**：段を終え、目数の警告を出す
  - **戻って続ける**：段の入力に戻る

拾いすぎている場合はこの確認を出さず、段を終えた時点で目数表に警告を出す（ドメイン仕様23）。

### 7-3. 書き出し前の確認
- メッセージ例：「目数が合っていない段があります（3段目）。このまま書き出しますか？」。複数の段なら「3・4段目」のように並べる
- 選択肢：書き出す／キャンセル
- 入力を始めていない末尾の空の段は対象にしない。入力途中の段（目が入っているが終えていない段）は対象にする

### 7-4. 立ち上がりを数えるかの確認
設定「立ち上がりを1目と数える」が「毎回選択」のとき、立ち上がりが入る直前（U5 の自動挿入、U23 の立ち上がりボタン）に出す。
- メッセージ例：「立ち上がり鎖3目を1目と数えますか？」
- 選択肢：数える／数えない／キャンセル（キャンセルすると立ち上がりも目も入れない。先に選ぶ状態は残る）
