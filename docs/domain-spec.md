# かぎ針編み図アプリ ドメイン仕様書

このドキュメントは、かぎ針編みのルールをアプリのデータと動作にどう落とし込むかを定義する。画面構成・操作方法・技術選定は別の仕様書で扱う。

各項目の番号（1〜33）は仕様検討時の番号で、欠番や順序の入れ替わりがある。33 は実装前のレビューで追加した。

---

## 0. 前提

- **対象**：かぎ針編み（棒針編みは対象外）
- **対応端末**：iPhone・iPad（どちらでも作図する）
- **基本方針（構造モデル）**：記号を見た目の位置で配置するのではなく、「どの目がどの目に編み入れられているか」というつながりをデータとして持つ。目数表・平面図・円形図・（将来の）立体プレビューは、すべて同じデータから生成する表示とする。
- **入力方式**：記号ボタンで1目ずつ編み進める、実際に編む感覚の入力。
- **背景**：既存アプリには、鎖編みのアーチ構造が反映されない、輪編みで記号の角度を1目ずつ手で調整する必要がある、繰り返しの入力が弱い、といった不満がある。本仕様はこれらをデータ構造の段階で解決することを狙う。

## 用語

コード内の命名には英語名を使う。かぎ針の英語名はUS式とUK式で名称がずれるため、**US式で統一する**。

| 用語 | 意味 | 英語（US） |
|---|---|---|
| 目 | 編み目1つ | stitch |
| 段 | 編み地の1列。輪編みでは1周 | row / round |
| 往復編み | 段ごとに編み地を返す編み方 | worked flat（コードでは `flat`） |
| 輪編み | 段の終わりを引き抜きで閉じる編み方 | joined rounds |
| 螺旋編み | 閉じずにぐるぐる編む編み方 | spiral / continuous rounds（コードでは `spiral`） |
| 操作 | 手順を構成する1つの操作（目を編む、飛ばす、など） | step（コード上の名前。operation は標準ライブラリと衝突するため避ける） |
| 前段 | 今編んでいる段の1つ前の段 | previous row |
| 拾う | 前段の目に針を入れて編むこと | work into |
| 編み入れ先 | 目を編み入れる場所 | — |
| 束に編み入れる | 鎖編みのループ全体をすくって編む | work into chain space |
| わの作り目 | 糸で輪を作り、その中に編み入れる作り目 | magic ring |
| 鎖の作り目 | 鎖編みを必要数編んで土台にする作り目 | foundation chain |
| 立ち上がり | 段の始めに編む鎖 | turning chain / starting chain |
| 段を閉じる引き抜き | 輪編みで段の終わりに、段の最初の目へ引き抜いて輪を閉じること | closing slip stitch |
| 増し目 | 同じ目に2目以上編み入れる | increase |
| 2目一度 | 前段の2目をまとめて1目にする | decrease (e.g. sc2tog) |

## 1. 目と編み入れ先

### 1. 基本の目の種類

初期バージョンは次の6種類のみ対応する。図での高さは立ち上がりの鎖の目数に対応させる。

| 目 | 英語（US） | 図での高さ | 前段を拾う数 |
|---|---|---|---|
| 鎖編み | chain | 高さなし（横に連なる） | 0 |
| 引き抜き編み | slip stitch | ほぼ高さなし | 1 |
| 細編み | single crochet | 鎖1目分 | 1 |
| 中長編み | half double crochet | 鎖2目分 | 1 |
| 長編み | double crochet | 鎖3目分 | 1 |
| 長々編み | treble crochet | 鎖4目分 | 1 |

### 2. 増し目・減らし目は「目の種類」として持たない

- 「細編み2目編み入れる」は、**同じ編み入れ先を持つ細編み2目**として記録する。
- 「細編み2目一度」は、**前段の2目を編み入れ先に持つ細編み1目**として記録する。
- 目数は2に限らず n目（n≧2）に一般化する。「n目編み入れる」は同じ編み入れ先を持つ n目、「n目一度」は前段の n目を編み入れ先に持つ1目として記録する。
- 記号図に描くときは、この組み合わせを検出してV字・逆V字の記号（3目以上は根元を1点に集めた n本の記号）にまとめる。
- 入力画面では「n目編み入れる」「n目一度」を先に選んでから目ボタンを押す形で提供する（ui-spec 5-6）。

### 3. 編み入れ先の種類（初期対応）

- 前段の目の頭に編み入れる
- 鎖のループや前段のすき間に束で編み入れる
- わの作り目に編み入れる
- 鎖の作り目に編み入れる

すじ編み・うね編み・引き上げ編みは今後の拡張とする。

### 4. 鎖編みは前段に編み入れない

鎖編みは、同じ段の直前の目からつながって伸びる目として扱う。モチーフの「鎖5目のアーチ」は連続した鎖編みで表し、次の段はそのアーチ全体に束で編み入れる。

## 2. 段の始まりと終わり

### 5. 編み方の種類

| 編み方 | 内容 | 立ち上がり | 段を閉じる引き抜き |
|---|---|---|---|
| 往復編み | 段ごとに編み地を返す | あり | なし |
| 輪編み | 段の終わりを引き抜きで閉じ、立ち上がってから次の段へ進む | あり | あり |
| 螺旋編み | 段の境目で閉じずに、ぐるぐる編み進める（あみぐるみで多用） | なし | なし |

**螺旋編みの段の区切り**：境目を閉じないため、データ上の区切りは目数から自動では決めず、ユーザーが「段を終える」操作で置く（ui-spec 5-6）。螺旋編みでは立ち上がりも段を閉じる引き抜きも入れない。

### 6. 立ち上がりの鎖

立ち上がりは、普通の鎖編みとは**別の操作**として記録する（手順の表示や、段の目数の数え方が鎖編みと異なるため）。

| 段の最初の目 | 立ち上がりの鎖 | 目数に数えるか |
|---|---|---|
| 引き抜き編み | なし | — |
| 細編み | 鎖1目 | 数えない |
| 中長編み | 鎖2目 | 1目と数える |
| 長編み | 鎖3目 | 1目と数える |
| 長々編み | 鎖4目 | 1目と数える |

- **数えるかどうかは、立ち上がりの鎖の目数で決める**：1目なら数えない、2目以上なら1目と数える。段にどの目が含まれているかでは判定しない。
- 1目と数える立ち上がりは、段の1目めとして前段の1目を拾う（21の表を参照）。数えない立ち上がりは前段を拾わず、目としても数えないが、図には描く。
- 上の表は、入力時に自動で入れる立ち上がりの初期値である。ユーザーは立ち上がりの鎖の目数を1〜4目の範囲で手動で変えられる（ui-spec 5-6）。
- 立ち上がりが自動で入るのは、その段で最初に鎖以外の目を編んだときの1回だけ。後から段の目の種類を変えても、立ち上がりは自動では変わらない（変更を提案する機能は今後の拡張）。

### 7. 輪編みの段の終わり（段を閉じる引き抜き）

輪編みでは、段の終わりに段の最初の目へ引き抜いて輪を閉じる。この引き抜きは「段を終える」操作で自動的に入る**特別な操作**として記録し、普通の引き抜き編みとは区別する。

- 編み入れ先は「今の段の1目め」。立ち上がりを1目と数える段では立ち上がり（長編みの段なら鎖の3目め）、数えない段では段の最初の目になる。
- 前段の目を拾わず、目数にも数えない（21の表を参照）。図には引き抜き編みの記号で描く。
- 往復編み・螺旋編みでは入らない。

### 8. 段の目数の表示

鎖を含む段では、**合計目数**と**鎖を除いた目数**を併記する。
- 立ち上がりの鎖を1目と数える段では、立ち上がりは両方の目数に1目として含める（鎖として複数目には数えない）。
- 数えない立ち上がり（鎖1目）は、どちらの目数にも含めない。
- 段を閉じる引き抜きは、どちらの目数にも含めない。

### 9. 往復編みの表示

段ごとに読む方向が反転するため、立ち上がり側に段番号と方向の矢印を付ける。

### 33. 作り目

作り目は段に含めない。段番号は、作り目に編み入れる段を1段目として数える。目数表では先頭に作り目の行を表示する。

**わの作り目**
- 1段目は何目でも編み入れられる。整合性チェック（23）の対象外とし、「前段の目数」は表示しない。

**鎖の作り目**
- 保存するのは「1段目に編む目数 n」。作品作成時にユーザーが入力するのもこの数（ui-spec 4）。
- 実際に編む鎖の目数は計算して表示する：**n ＋ 1段目の立ち上がりの鎖の目数 −（立ち上がりを1目と数える場合は 1）**
  - 細編み20目 → 鎖21目（20 + 1）
  - 長編み20目 → 鎖22目（20 + 3 − 1）
- 1段目の立ち上がりが決まる前は、細編みの段を想定して n + 1 目で仮表示する。
- 1段目の整合性チェックでは「前段の目数」を n として扱う。
- 作り目の鎖のどこを拾うか（裏山など）は区別しない。区別は今後の拡張とする。

## 3. 記号

### 10. 記号の基準

JISの編目記号の形に準拠する。記号は画像素材ではなく、アプリ内でベクターの線として描画する（拡大表示・ベクターPDF書き出しに対応するため）。

### 11. 組み合わせの描き分け

- 同じ目に編み入れた目は、記号の根元を1点に集めて描く。
- 束に編み入れた目は、記号の根元を離して描く。

3の編み入れ先の区別から自動で判定する。

### 12. 記号の向き

円形図では、記号の根元が編み入れ先の方向を向くように自動で回転させる。ユーザーが角度を調整する操作は設けない。

### 13. 凡例

書き出し時に、その図で使用した記号のみの凡例を自動生成する。

### 14. 対象外

カスタム記号と英語圏の記号体系への対応は今後の拡張とする。

## 4. 繰り返し

### 15. 段の中の繰り返しは繰り返しのまま記録する

「（細編み1目、増し目）×6」を、展開した目の列ではなく「繰り返し単位＋回数」として記録する。
- 繰り返し単位を編集すると、すべての回に反映される。
- 1回分だけ変更したい場合は、その繰り返しを解除して個別の目に展開してから編集する。

### 16. 端数

「（細編み2目、増し目）×6、細編み3目」のように、繰り返しの後に続く目は繰り返しの外の目として続けて記録する。

### 17. 「全目に」「段の終わりまで」の指定

回数を固定せず、前段の目数に合わせて決まる指定を持つ。
- 「残りの目すべてに細編み」
- 「残りの目すべてに増し目」（残りすべてに n目編み入れる・n目一度・束に、も同様）
- 「（細編み1目、増し目）を段の終わりまで」

前段の目数が変わった場合は**自動で追従する**。回数を固定した段（「×6」など）は追従せず、合わなければ23の警告対象になる。

**回数の決め方**：繰り返し単位を最後まで編める回数だけ繰り返す。前段の残りが単位の拾う数で割り切れない場合、余った前段の目は拾わずに残す。残った目は「段を終える」ときの確認（ui-spec 7-2）で「残りは編まない」を選ぶか、そのまま終えて23の警告にする。
- 例：（細編み1目、増し目）を段の終わりまで、前段13目 → 6回（12目拾う）で1目残る。
- 「残りの目すべてに2目一度」で残りが奇数のときも同じ。

**使えない場合**：前段を1目も拾わない単位（鎖編みだけ、など）には「段の終わりまで」を指定できない（回数が決まらないため）。

### 18. 段の繰り返し

「増減なしで5段」のような指定は、段の複製（回数を指定）で一括作成する（ui-spec 5-4）。データ上は1段ずつ独立した段として持つ。目数表では、同じ内容の段が連続していることを自動検出し、「5〜9段目：細編み30目（増減なし）」のようにまとめて表示する。

### 19. 図と目数表での表示

- 図にはすべての目を描き、繰り返し範囲を括弧などで示す。
- 目数表・文章パターンでは「（…）×6」と表記する。

## 5. 修正と整合性

### 21. 段は「前段の目を順に拾っていく手順」として記録する

各段は、前段の目を端から順に消費していく操作の列として記録する。

| 操作 | 前段を拾う数 | 生まれる目 |
|---|---|---|
| 立ち上がり（1目と数える。鎖2目以上） | 1 | 1 |
| 立ち上がり（数えない。鎖1目） | 0 | 0（図には描く） |
| 普通の目（細編みなど） | 1 | 1 |
| n目編み入れる（増し目） | 1 | n |
| n目一度 | n | 1 |
| 鎖編み | 0 | 1 |
| 束に編み入れる | 鎖のアーチ1つ | 編み入れた数 |
| 前段の目を飛ばす（22） | 飛ばした数 | 0 |
| 残りは編まない（23） | 残り全部を終了扱い | 0 |
| 段を閉じる引き抜き（7） | 0 | 0（図には描く） |

段の先頭に立ち上がりがある場合、立ち上がりは常に段の最初の操作になる（鎖編みから始まる段でも、立ち上がりはその鎖より前に置く）。

### 22. 「前段の目を飛ばす」操作

モチーフの「2目飛ばして長編み」などに使う。

### 23. 整合性チェック

段ごとに「その段で拾った目数」と「前段の目数」を比較し、合わない場合はその段に警告を出す。足りない場合だけでなく、拾いすぎた場合も警告の対象になる。

- 警告の文言例：「前段30目のうち28目しか拾っていません」「前段30目に対して32目拾っています」
- 「残りは編まない」操作を使った段では、拾わなかった残りの目について警告を出さない（往復編みで端の目をわざと残して返す場合など）。
- 入力中の段は、段を終えるまで警告の対象にしない（拾いすぎの警告も、段を終えたときに出す）。
- わの作り目に編み入れる1段目は、何目でも編み入れられるため整合性チェックの対象外とする。
- 警告のある段は、目数表と図の両方で色を変えて示す。
- 警告がある状態でも保存はできる。書き出し時のみ「目数が合っていない段があります」と確認を出す。

### 24. 拾う目数が変わらない修正

細編みを中長編みに変えるなど、拾う目数も生まれる目数も変わらない修正は、上の段に影響しないためそのまま反映し、図を再描画する。確認は出さない。

### 25. 目数が変わる修正

上に段がある状態で目数が変わる修正をしたときは、確認を出してユーザーに選ばせる。

- 影響範囲を表示する（例：「3〜5段目に影響があります」）
- 選択肢は次の3つ：
  - **上の段を残す**：上の段は同じ手順のまま新しい前段から拾い直し、合わなくなった段に23の警告を出す
  - **上の段をほどく**：修正した段より上の段を削除する
  - **キャンセル**：修正を取りやめる

段の削除、および段の複製（複製した段はその段の直後に挿入される）でも、上に段がある場合は同じ確認を出す。段の途中への任意の挿入は今後の拡張とする。

### 26. 元に戻す・やり直し

すべての編集操作を取り消し・やり直しできる。回数制限や有料機能化はしない。

## 6. 色

### 27. 色は目ごとに持つ

データ上は1目ずつ糸の色を記録する。段ごとのボーダーも、目単位の配色模様も、同じ仕組みで表現する。

### 28. 色の指定方法

- 通常は段全体の色を指定する（「この段は白」）。
- 目を選択して個別に色を変更できる。

### 29. 糸リスト

作品ごとに使用する糸を登録する。項目は、表示色・名前（「白」「メイン色」など）・メモ（糸の品番など、任意）。

### 30. 図での表示

記号の線を糸の色で描画する。白など背景に近い色は、判別できるよう輪郭を付ける。

### 31. 色替え位置の表示

実際の編み方では前の目の最後の引き抜きで新しい色に替えるため、図と目数表で「どの目で色を替えるか」を自動で示す。

## テストケース例

実装時の自動テストの元にする。編み物の観点で内容を確認し、随時追加する。

### TC-1 わの作り目からの輪編み（細編み）

| 段 | 手順 | 期待される目数 |
|---|---|---|
| 1 | わの作り目に細編み6目、1目めに引き抜き | 6目（立ち上がり鎖1と引き抜きは数えない） |
| 2 | 全目に増し目 | 12目 |
| 3 | （細編み1目、増し目）×6 | 18目 |
| 4 | （細編み2目、増し目）×6 | 24目 |
| 5 | 残りの目すべてに細編み | 24目 |

### TC-2 修正時の自動追従と警告（TC-1の続き）

1段目を「わの作り目に細編み7目」に修正し、「上の段を残す」を選んだ場合：

| 段 | 期待される結果 |
|---|---|
| 1 | 7目 |
| 2 | 14目（「全目に」なので自動追従、警告なし） |
| 3 | 18目のまま。警告「前段14目のうち12目しか拾っていません」 |
| 4 | 24目のまま（前段18目を過不足なく拾うため警告なし） |
| 5 | 24目のまま、警告なし |

同じ修正で「上の段をほどく」を選んだ場合は、2〜5段目が削除され、1段目（7目）のみが残る。

### TC-3 長編みの段の立ち上がり

前段12目に対して「立ち上がり鎖3目、長編み11目、立ち上がり鎖の3目めに引き抜き」
→ 12目（立ち上がり鎖3目を1目と数える。引き抜きは数えない）

### TC-4 鎖を含む段の目数表示

前段12目に対して「立ち上がり鎖3目、鎖2目、（長編み1目、鎖2目）×11、立ち上がり鎖の3目めに引き抜き」
→ 合計36目／鎖を除いて12目（立ち上がりは1目として数える）
→ 前段の拾った目数は12目で、警告なし

### TC-5 拾う目数が変わらない修正

TC-1の3段目の細編みをすべて中長編みに変更
→ 確認は出ず、4段目以降に影響なし。図の記号の高さのみ変わる

注記：この段の立ち上がりは鎖1目（数えない）のまま変わらない。立ち上がりは自動では変わらないため（6）、段の目数は18目のままで上の段に影響しない。

### TC-6 「段の終わりまで」で割り切れない場合

前段13目に対して「（細編み1目、増し目）を段の終わりまで」
→ 6回繰り返して18目。前段の1目が拾われずに残る（17）
→ そのまま段を終えると警告「前段13目のうち12目しか拾っていません」。「残りは編まない」を選べば警告なし

### TC-7 鎖の作り目の目数表示

「1段目に編む目数」を20として鎖の作り目で作品を作成
- 1段目を編み始める前 → 作り目の表示は鎖21目（仮表示）
- 1段目の最初に細編みを編む（立ち上がり鎖1目が入る） → 鎖21目
- 1段目の最初に長編みを編む（立ち上がり鎖3目が入る） → 鎖22目。1段目は立ち上がり＋長編み19目で20目
